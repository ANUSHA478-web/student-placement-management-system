# Student Placement Management System

## About the Project
The Student Placement Management System is a web application developed using Python, Flask, and MySQL to manage student placement activities.

## Features
- Student Management
- Company Management
- Job Management
- Apply for Jobs
- View and Manage Applications
- Eligible Jobs
- Update Application Status
- Student Placement Reports
- Export Reports to CSV

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS

## How to Run
1. Install Python.
2. Install the required packages using `pip install -r requirements.txt`.
3. Configure your database connection using environment variables or a local `config.py` file.
4. Run the application using `python app.py`.
